---

## 🌷 About the Project

The **Personal Journal Manager** is a menu-driven Python application designed to help users maintain their daily thoughts and memories. It stores journal entries in a text file along with the date and time of each entry.

This project demonstrates the practical use of Python programming, file handling, and Object-Oriented Programming (OOP).

## ✨ Features

- ✍️ **Add a New Entry:** Write and save a journal entry with a timestamp.
- 📖 **View All Entries:** Display all previously saved journal entries.
- 🔍 **Search for an Entry:** Find entries using a keyword or date.
- 🗑️ **Delete All Entries:** Delete all saved entries after confirmation.
- 🚪 **Exit:** Close the application safely.

## 🛠️ Technologies Used

- 🐍 Python 3
- 📂 File Handling
- 🕒 Datetime Module
- ⚙️ OS Module
- 🧩 Object-Oriented Programming (OOP)

## 💻 Requirements

- Python 3.x installed on your computer
- Visual Studio Code or any Python IDE

## 🚀 How to Run the Project

**Step 1:** Open the project folder in Visual Studio Code.

**Step 2:** Save the Python code as `project 6.py`.

**Step 3:** Open the terminal in the project folder.

**Step 4:** Run the following command:

```bash
python "project 6.py"
```

**Step 5:** Select an option from the menu to start using the application. 🎉
